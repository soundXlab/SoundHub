Introduction to SoundHub

SoundHub is a collaborative cloud workspace for music producers, sound engineers, and labels. It combines version control, review workflows, audio analysis, and marketplace publishing into one platform.

💡 New to SoundHub? Start with the Quick Start guide to create your first project in under 2 minutes.

Key Features

  • Version Control — Git-like branching for audio. Upload versions, create branches, and compare changes.
  • Review Workflows — Request feedback, leave timestamped comments, and approve/request changes.
  • Audio CI — Automated loudness, waveform, and metadata checks on every upload.
  • Marketplace — Publish and sell your audio assets. Royalty-free licensing built in.
  • DAW Integration — Max for Live, REAPER, and FL Studio plugins for seamless workflow.

How It Works

1. Create a Project

Start by creating a project and uploading your DAW file or stems. SoundHub supports Ableton Live (.als), FL Studio (.flp), REAPER (.rpp), and standard audio formats.

snd project create "My New Track"
snd upload ./my-project.als

2. Upload Versions

Each time you make changes, upload a new version. SoundHub tracks the full history and generates waveforms, loudness analysis, and metadata automatically.

3. Request Review

Share a review link with collaborators. They can listen, leave timestamped comments, and approve or request changes — all without creating an account.

✅ Pro tip: Use the share link to get feedback from clients who don't have a SoundHub account. They can comment and approve directly in their browser.
