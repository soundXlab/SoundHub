CLI Reference

Command-line interface for SoundHub — snd

📦 Installation
Install the SoundHub CLI tool
npm
pip
brew
$ npm install -g @soundhub/cli
# or
$ pip install soundhub-cli
# or
$ brew install soundhub/tap/snd
🔐 Authentication
Login and manage API credentials
# Login with browser OAuth
$ snd login

# Or set token directly
$ snd auth --token snd_abc123...

# Check auth status
$ snd whoami
Logged in as @producer1 (plan: pro)

⬆️ Push & Pull
Upload and download project files
# Push current directory to SoundHub
$ snd push
⟳ Analyzing project files...
✓ Found 12 audio files (245 MB)
⟳ Uploading v14...
✓ Push complete — v14 published

# Push with message
$ snd push -m "Added vocal stem"

# Pull latest version
$ snd pull

# Pull specific version
$ snd pull --version v12

# List remote versions
$ snd versions
v14 2h ago 142 MB "Added vocal stem"
v13 1d ago 138 MB "Pre-master"
v12 3d ago 135 MB "Rough mix"
🛒 Marketplace
Search, buy, and publish assets
# Search marketplace
$ snd search "lo-fi drums"

# Download an asset
$ snd buy lo-fi-drums-pack

# Publish your asset
$ snd publish --price $9.99 --tags lo-fi,drums
