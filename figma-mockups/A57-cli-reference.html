📦 Installation #
Install the SoundHub CLI tool globally
npm
pip
brew
📋 Copy
$ npm install -g @soundhub/cli # or $ pip install soundhub-cli # or $ brew install soundhub/tap/snd # Verify installation $ snd --version ✓ snd v2.1.0
🔐 Authentication #
Login and manage API credentials
📋 Copy
# Login with browser OAuth $ snd login ✓ Opening browser for authentication... ✓ Logged in as @producer1 (plan: pro) # Or set token directly $ snd auth --token snd_abc123... ✓ Token saved to ~/.snd/config # Check auth status $ snd whoami User: @producer1 Plan: Pro ($19/mo) Projects: 12 Storage: 2.1 GB / 10 GB

🛒 Marketplace #
Search, buy, and publish assets
📋 Copy
# Search marketplace $ snd search "lo-fi drums" Found 12 assets matching "lo-fi drums" #1 Lo-Fi Drums Pack Free ★ 4.8 (124) #2 Chill Lo-Fi Beats $4.99 ★ 4.6 (87) ↓ 10 more results # Download an asset $ snd buy lo-fi-drums-pack ✓ Downloaded to ./assets/lo-fi-drums-pack/ # Publish your asset $ snd publish --price $9.99 --tags lo-fi,drums ✓ Published to marketplace — 808-bass-kit
