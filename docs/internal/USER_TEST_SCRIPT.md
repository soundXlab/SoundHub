# User Testing Script — Review Player

## Участники
1. **Buffy** (CEO) — контролирует процесс, фиксирует результаты
2. **Scatter** (CEO founder) — тестирует как клиент
3. **Claude** (Lead Dev) — тестирует как гость/рецензент

## Тест-сценарии

### Сценарий 1: Создание сессии (Инженер)
1. Залогиниться как demo/demo123
2. Перейти на /reviews
3. Создать новую сессию "Test Mix v1"
4. Загрузить аудиофайл (mix_v1.wav)
5. **Проверить:** waveform отображается, метаданные корректны

### Сценарий 2: Публичная ссылка (Гость)
1. Скопировать публичную ссылку /r/{token}
2. Открыть в новом окне (без логина)
3. **Проверить:** страница загружается без 403
4. Оставить комментарий по таймкоду (0:45)
5. **Проверить:** комментарий сохраняется

### Сценарий 3: A/B Сравнение (Инженер)
1. Загрузить v2 (исправленная версия)
2. Открыть A/B сравнение
3. **Проверить:** переключение между версиями работает

### Сценарий 4: Approve Flow (Клиент)
1. Открыть публичную ссылку
2. Нажать "Approve"
3. **Проверить:** статус меняется на "approved"

### Сценарий 5: Ledger (Инженер)
1. Проверить ledger в сессии
2. **Проверить:** все события записаны, hash chain целостна

## Метрики
- Время на каждый шаг
- Количество ошибок
- NPS (0-10)
- Комментарии по UX
